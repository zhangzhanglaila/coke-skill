## 反爬与合规

- **限速**：同一域名 ≥2 秒/请求；单次任务总量控制在几十个页面内。
- **静态优先**：`fetch_page.py` 只处理纯 HTML；遇到「登录 / 验证 / 空白正文」立即转浏览器工具人工浏览。
- **不绕过**：不破解签名、不刷接口、不批量下载视频/图片。
- **只取文本**：抓取只保留文字正文用于个人整理与检索，不镜像整站内容。
- **保留出处**：每条语录必须带 `source_url`；导出分享时保留来源与作者署名。

## 抖音抓不到的兜底路径

抖音正文脚本抓不到时，用这套替代链路：
1. 搜索引擎侧面检索：`"<记忆中的原句>" coke` → 常能命中百科/梗站/盘点文，反查出原句与出处。
2. 搜「coke + 名场面 + 台词」「coke + 切片 + 字幕」。
3. 用已知的梗去反查未知：每个已入库的梗，去搜它的「下一句」「完整版」「出处」。
4. 浏览器工具打开话题页/搜索页，人工滚动 + 复制。
