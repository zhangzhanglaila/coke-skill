# 抽取与判定规则

## 一、什么算「他说的话」

✅ 收：
- 直播/连麦/PK 中说出的句子（切片字幕、盘点文引用均可）
- 视频中本人出镜说的话、视频文案里的自述
- 综艺/采访/线下活动中的本人发言
- 本人微博、抖音文案、评论区本人回复
- 空耳变体（网友听错但广泛传播的版本），标记 `variant_of` 指向原句

❌ 不收：
- 旁白、记者/小编的转述与评价（"他表示……""网友纷纷……"）
- 网友评论、二创文案、仿写、AI 生成句
- 他人对他说的话
- 他人给他起的称号本身（可入库但 `type=称号`，不计入语录）
- 只有动作没有语言的名场面（可记入 `type=名场面`，text 写场景描述）

## 二、清洗

1. 去掉引号外壳，保留原标点与语气词（「啊」「吧」「嘛」是梗的一部分）。
2. 统一全角标点；不改写方言/空耳用字（「我嘞个骚刚」不改成「我勒个」）。
3. 一句话一条；带上下文的把场景写进 `scene`，不要塞进 `text`。
4. 长度：2–60 字为宜，超 80 字基本是转述，降权。

## 三、置信度分级

| 分 | 含义 | 依据 |
|---|---|---|
| 0.95 | 一手视频/直播切片，肉眼可核 | 原视频 URL + 时间码 |
| 0.9 | 权威词条/多家媒体一致引用 | 百度百科、梗百科、媒体稿 |
| 0.8 | 盘点文/自媒体引用，措辞一致 | 单篇文章，有引号 |
| 0.6 | 二手转述，措辞可能有出入 | 无引号的转述 |
| <0.5 | 存疑，需复核 | 仅见于一处、来源不明 |

`verified=true` 只在人工复核过（看过原视频或≥2 个独立来源）后设置。

## 四、去重

- 归一化：去标点/空格/全半角差异 → `norm`。
- 完全相同 `norm` 直接丢弃。
- `difflib.SequenceMatcher` 相似度 ≥0.88 视为重复，保留信息更全的一条，短的进 `variant_of`。
- 空耳与原句不合并，用 `variant_of` 关联。

## 五、分类标签

`type`：口头禅 / 名场面 / 连麦PK / 直播 / 综艺 / 采访 / 短视频 / 评论区 / 称号 / 设定
`tags`：嘲讽 / 自嘲 / 接梗 / 荒诞追问 / 成语误用 / 火影 / 出圈梗 / 卖货 / 恐怖游戏 / 二创相关 ……

## 六、harvest.py 打分逻辑（可解释）

```
+3  被中文引号 “…” 或 "…" 包裹
+3  命中 lexicon.txt 已知梗词
+2  含 老弟 / 痞 / 我嘞个 / 咪咪 / 阿玛特拉斯
+1  长度 4–30 字
+1  句首紧邻「他说/一句/来了句/脱口而出」等引导词
-2  含 网友说 / 据说 / 表示 / 记者 / 小编 / 本文 / 版权 / 侵权 / 关注
-2  长度 > 80 字
-1  以「的」「了」结尾且无引号（大概率是叙述碎片）
```
输出按分数降序，人工只看前 N 条即可。
